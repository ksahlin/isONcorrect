Note: git stores each distinct blob once, so identical files at different
paths are counted under whichever path reaches them first. This is not
cosmetic -- it reflects real storage. Two consequences worth knowing:

  * test_data/chr6_ensemble.fa and data/chr6_transcripts.fa are byte-identical.
    Both are stripped, so the shared blob genuinely goes away.

  * test_data/isoncorrect/0.fastq, test_data/isoncorrect/1.fastq and
    test_data/100reads.fq are ALL THE SAME FILE (one blob, three paths).
    The 'two test clusters' used by CI and by bench/ are one cluster twice.
    Stripping is path-based, so keeping them is still correct -- but do not
    mistake them for independent test coverage.
